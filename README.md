# Swapno Tech

Swapno Tech is a creative technology and digital business solutions company building an agency website and connected digital ecosystem.

## Product areas
- Website Solution: guided section-based website builder.
- Creator Platform: professional profiles, portfolios and discovery.
- Hosting: verified plans and enquiry coordination.
- Swapno Founders: moderated community for entrepreneurs and business owners.

The three core products are Website Solution, Creator Platform and Hosting. Swapno Founders is a separate community area.

## Technical direction
- Frontend: React + Vite.
- Backend: Supabase, pending project/environment setup approval.
- Source control: GitHub.
- Preview/deployment: Vercel, pending configuration.
- Design: Figma; Canva is the brand asset source.

## Non-negotiables
Fast loading, connected visual storytelling, meaningful design, clear UX, accessibility, mobile quality, security and incremental verification.
